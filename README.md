# mxm-fx-eq-n

A parametric EQ with only the bands you need: up to 24, each one added where it is wanted. Every
band is matched to its analogue curve right up to the top of the range, so a boost at 15 kHz sounds
like one, and a cut exactly cancels the same boost.

Eight shapes — bell, low and high shelf, low and high cut (6 to 96 dB/octave), notch, band pass and
tilt shelf — with band solo, a gain scale, an output gain and an animated spectrum. Zero latency.

**Status:** pre-alpha, in development. See [`AGENTS.md`](AGENTS.md) and
[`plans/plan-mxm-fx-eq-n.md`](plans/plan-mxm-fx-eq-n.md).
